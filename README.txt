PROJECTE BOSSES DE TELA · QUIZ MULTIJUGADOR

Funcions:
- Sala multijugador amb codi de sis caràcters.
- Vestíbul en directe amb noms i avatars d'animals.
- L'amfitrió pot veure qui entra i iniciar la partida.
- 10 preguntes en valencià, temporitzador i punts per rapidesa.
- Podium final i classificació completa.
- Disseny adaptable a mòbils i ordinadors.

PUBLICAR EN RENDER
1. Puja els fitxers server.js, package.json i render.yaml al repositori GitHub.
2. Puja index.html al directori arrel del repositori (aquesta versió també serveix public/index.html si existeix).
3. A Render, crea un Web Service i connecta aquest repositori.
4. Build Command: npm install
5. Start Command: npm start
6. Deploy. Quan acabe, obri l'URL que Render et done.

No uses GitHub Pages/Static Site: aquest projecte necessita Node.js i Socket.IO.
